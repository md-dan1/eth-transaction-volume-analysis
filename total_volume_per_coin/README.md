This folder contains December 2025 Ethereum transaction volume broken down by coin:
- `volume_per_coin_december_2025.csv` ;-delimited, one row per block (`block_number;timestamp;<coin>…`)
- `accumulated_total_volume_per_coin_dec_2025.csv` — cumulative month total as coins are added (`added_coin,num_coins,total_volume_usd`)
- `accumulated_total_volume_per_coin_dec_2025.png` — the chart rendered from it

Columns are the top-20 coin set listed in /top_coins_by_tx_count.txt.
Values are in USD.
